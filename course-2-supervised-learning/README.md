# Course 2: Solving Business Problems With Supervised Learning

Supervised learning: neural networks, hyperparameter tuning, regularisation, decision trees and ensemble methods.

## Activities

| File | Activity | Summary |
|---|---|---|
| activities/Activity_1.1.4_Classification_vs_Regression.ipynb | Identifying classification vs regression | Deciding whether each of six business scenarios is a classification or regression problem |
| activities/Activity_2.3.4_Manual_Forward_Propagation.ipynb | Performing manual forward propagation | Working through forward propagation in a neural network by hand |
| activities/Activity_3.1.5_Building_a_Basic_Neural_Network.ipynb | Building a basic neural network | Building a first neural network classifier |
| activities/Activity_3.2.3_Hyperparameter_Tuning.ipynb | Experimenting with hyperparameter tuning | Tuning network hyperparameters and comparing results |
| activities/Activity_3.3.6_Evaluation_Metrics.ipynb | Exploring evaluation metrics | Evaluating a classifier with metrics beyond accuracy |
