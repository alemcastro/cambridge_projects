# Course 3: Applying Advanced Data Science Techniques

Natural language processing (sentiment analysis, text classification, topic modelling) and time series forecasting.

## Activities

| File | Activity | Summary |
|---|---|---|
| activities/Activity_1.3.4_Sentiment_Analysis.ipynb | Sentiment analysis | Sentiment analysis on a public text dataset |
| activities/Activity_2.2.6_Sentiment_and_Text_Classification.ipynb | Sentiment analysis and text classification | Classifying text and comparing sentiment outputs |
| activities/Activity_6.5_Preparing_for_Time_Series.ipynb | Preparing for time series analysis | Loading and preparing time series data in Python |
| activities/Activity_7.3.3_ARIMA_Models.ipynb | Performing ARIMA models | Fitting and interpreting ARIMA models |
| activities/Activity_8.2.3_Time_Series_Forecasting_with_ML.ipynb | Time series forecasting with machine learning | Forecasting a time series with machine learning methods |

## Projects

| File | Project | Summary |
|---|---|---|
| projects/Topic-project_NLP_Topic_Modelling_Reviews.ipynb | NLP topic modelling of customer reviews | Topic modelling (LDA/Gensim and BERTopic) on customer reviews to surface key themes |
| projects/Topic-project_Time_Series_Sales_Forecasting.ipynb | Time series sales and demand forecasting | Forecasting weekly and monthly sales with ARIMA/SARIMA and hybrid models |

Dataset links have been replaced with placeholders, and the topic projects' cell outputs were cleared to remove real company data, so these notebooks need their data to run.
